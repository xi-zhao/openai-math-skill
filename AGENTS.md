# AGENTS.md

This repository is an agent skill, not an application. The skill itself is [`SKILL.md`](SKILL.md).

- When the user asks for help with a research problem in mathematics, theoretical physics, CS theory, or another proof- or derivation-heavy field (finding open problems from a topic, writing a prove-or-refute statement, best-of-N solving, isolated review, Lean or computational verification), read `SKILL.md` in full and follow it. Its text is mostly Chinese; the prompt templates in §T are in English and are meant to be sent as written.
- Put research artifacts under `research/<id>/` as `SKILL.md` §9 describes, preferably in a separate working directory rather than inside this repository.
- When the user is editing this repository instead: do not change `SKILL.md` unless asked, and keep README claims consistent with what `SKILL.md` and the recorded test runs actually show.
